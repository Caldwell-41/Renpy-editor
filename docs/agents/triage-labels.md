# Triage labels

Use these labels when an engineering skill names a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Needs a human step: implementation, a hands-on check or acceptance |
| wontfix | wontfix | Will not be implemented |

A readiness label does not authorize work; the user selects it.
