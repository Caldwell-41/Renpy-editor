# Task brief template

Use this outline when selecting a substantial outcome. Copy the useful sections into
the owning brief and replace guidance with actual facts. Combine or omit sections
for a small task; this is not a required form or a second tracking system.
[WORKFLOW](../WORKFLOW.md#task-briefs-and-supporting-files) owns maintenance rules;
[ADR 0019](../adr/0019-task-briefs-and-evidence-ownership.md) explains the separation.

## Outcome and authorization

State the observable finished result and the user direction that selected it. Record
the current state, branch/worktree and chosen development host where relevant.
Distinguish permission to implement, verify, publish and accept when those differ.

## Scope and exclusions

Name the included operations and material boundaries. Link canonical contracts and
substantial requirements with a condition for reading each. Keep requirements needed
by every branch here; disclose independently selected branches through their owners.

## Acceptance and current results

Define criteria that distinguish completion from incomplete work. Beside each criterion
or coherent group, retain its current result and a direct link to supporting evidence.
Identify the qualified candidate where it affects reuse. Keep failed, missing and
pending proof visible, including any native or human acceptance still required.

Put detailed attempts, receipts and superseded directions in linked evidence when
history becomes substantial. Label links by their useful diagnosis, audit or reuse
condition. Use actual repository paths and fragments; omit links until targets exist.

## Limits, blockers and next action

Record applicable cumulative allowances, consumption and protected state needed to
continue. State material limitations and unresolved decisions with supporting evidence;
distinguish defects, harness failures and missing capability or proof. Give the next
concrete action and any required user decision. Replace superseded continuation text
when the state changes, preserving its useful history in the evidence record.
