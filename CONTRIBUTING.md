# Contributing

Thanks for considering a contribution to Project Loomlight / Renpy-editor.

## Before contributing

- Keep changes focused and consistent with `AGENTS.md` and the active project scope.
- Do not include secrets, personal data, private game content, proprietary assets, or
  material you do not have the right to contribute.
- Run the repository validation and the tests relevant to your change.
- Security vulnerabilities should be reported privately as described in `SECURITY.md`,
  not opened as public issues.
